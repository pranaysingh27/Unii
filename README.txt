ONE LAST UNIVERSE — PERSONALIZED WEBSITE

Included:
- index.html
- memories/ (9 photos, 3 short clips, and 1 longer video)

PREVIEW:
Open index.html in a browser. Keep the memories folder beside index.html.

PUBLISH WITH GITHUB PAGES:
1. Extract this ZIP.
2. Upload index.html and the entire memories folder into the root of your GitHub repository.
3. Commit the changes.
4. In repository Settings > Pages, select Deploy from a branch and choose your main branch / root if not already enabled.
5. Open your GitHub Pages URL.

Please keep the repository private unless you are sure she is comfortable with these photos/videos being publicly accessible. GitHub Pages sites from public repositories are generally public. You can also send the ZIP privately instead.
